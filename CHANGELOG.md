# BetterRimworlds.ChickenBatteryCage ChangeLog

## Unreleased

- Added a virtualized chicken-manure system: cages accumulate waste from hen count and elapsed game time (one pack per fifty hen-days, roughly 0.1 kg of manure per hen per day), cleaned in batches into haulable fertilizer packs.
- Added the `fertilizer pack` item, which dissolves one pack per stack every ten days and improves six natural terrain cells each time, using the same irregular outward-creeping cell selection as vanilla pollution.
- Added terrain reclamation: sand, stony soil, and rough natural cave stone become soil; constructed terrain, water, and buildings are never touched, and natural rock walls block the spread.
- Added virtualized vanilla `Toxic Buildup` for neglected cages, applied to a hen as a real Hediff when she is unloaded.
- Added cage inspect readouts for waste, cleaning status, fertilizer yield, and toxic buildup severity and trend.
- Added developer tools for fertilizer packs, cage waste, cleaning, and toxicity.
